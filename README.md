# ServiceBooking — Система онлайн-записи на услуги
Курсовой проект по веб-разработке (Вариант 7).  
Система предназначена для автоматизации онлайн-записи клиентов на услуги  с личным кабинетом клиента и полноценной панелью управления администратора.
---
## 🛠 Стек технологий
### **Backend (Сервер):**
- **Платформа:** .NET 8 (ASP.NET Core Web API)
- **База данных:** SQLite
- **ORM:** Entity Framework Core 8 (Code-First / Scaffolding)
- **Безопасность:** Хеширование паролей с солью (SHA-256)
- **Бизнес-логика:** 
  - Расчет времени завершения услуги на основе её длительности;
  - Контроль занятости слотов и учёт обязательного 15-минутного технического перерыва между записями (HTTP 409 Conflict);
  - Защита системного суперадминистратора (`root`) от удаления и перехвата логина.
### **Frontend (Клиент):**
- **Фреймворк:** Angular 22 (Standalone Components)
- **Реактивность:** Angular Signals (`signal`, `computed`)
- **Архитектура:** Zoneless Change Detection (`provideZonelessChangeDetection`)
- **Маршрутизация:** Angular Router (SPA с передачей параметров `/booking/:idService`)
- **Стили:** Vanilla CSS (адаптивная вёрстка, flexbox, CSS Grid)

## 🚀 Пошаговая инструкция по запуску
### 1. Запуск Backend (API-сервер)
> Требуется: установленный [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0).
1. Откройте терминал в папке API-сервера:
   ```bash
   cd server/ServiceBooking.Api/ServiceBooking.Api
Запустите проект:
bash
dotnet run
Сервер запустится и будет слушать запросы по адресу:
HTTPS: https://localhost:7210
Swagger UI (тестирование API): https://localhost:7210/swagger
2. Запуск Frontend (Angular-клиент)
Требуется: установленный Node.js (LTS v20+).

Откройте второй терминал в папке клиента:
bash
cd client
Установите зависимости (если запускается впервые):
bash
npm install
Запустите сервер разработки:
bash
npm start
Откройте браузер по адресу:
👉 http://localhost:4200

📋 Основные маршруты приложения (SPA)
Маршрут	Описание

/services	Главная страница: каталог услуг с реактивным поиском и фильтрацией

/booking/:idService	Страница оформления бронирования с контролем пересечения интервалов

/register	Личный кабинет: авторизация, регистрация, список «Мои записи», отмена брони

/admin	Панель управления (доступна только для пользователя root)
